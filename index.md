# Política de Privacidade — Pinho Konvertilo

**Última atualização: 28 de setembro de 2026**

Esta Política de Privacidade descreve como o **Pinho Konvertilo**, incluindo as edições **Pinho Konvertilo Free** e **Pinho Konvertilo Premium**, trata informações e arquivos utilizados durante o funcionamento do aplicativo.

O Pinho Konvertilo foi desenvolvido com foco em **privacidade, processamento local e funcionamento offline**. Seu princípio fundamental é simples: os arquivos escolhidos pelo usuário para conversão permanecem, sempre que tecnicamente possível, no próprio dispositivo.

Esta Política aplica-se às versões do Pinho Konvertilo distribuídas por meio da Google Play e por outros canais oficiais mantidos pelo desenvolvedor.

## 1. Princípio de privacidade

O Pinho Konvertilo foi projetado para realizar conversões diretamente no dispositivo do usuário.

Em condições normais de funcionamento:

- os arquivos selecionados para conversão não são enviados para servidores do desenvolvedor;
- o conteúdo dos arquivos não é utilizado para publicidade;
- o conteúdo dos arquivos não é vendido;
- o conteúdo dos arquivos não é utilizado para criação de perfis de usuário;
- não é necessário criar uma conta para utilizar o aplicativo;
- não é necessário fazer login para realizar conversões locais;
- o desenvolvedor não mantém uma cópia remota dos arquivos convertidos.

O Pinho Konvertilo procura minimizar o tratamento de dados e limitar qualquer acesso às informações estritamente necessárias para executar as funcionalidades solicitadas pelo próprio usuário.

## 2. Arquivos selecionados pelo usuário

Para realizar uma conversão, o usuário pode selecionar documentos, imagens, arquivos de áudio, vídeo ou outros formatos compatíveis.

O aplicativo precisa acessar o arquivo escolhido para:

- identificar seu formato;
- ler informações técnicas necessárias à conversão;
- realizar o processamento solicitado;
- gerar o arquivo convertido;
- permitir que o resultado seja salvo no local escolhido pelo usuário.

Esse processamento ocorre localmente no dispositivo.

O acesso a um arquivo para realização de uma conversão não significa que o arquivo esteja sendo enviado ao desenvolvedor.

## 3. Metadados dos arquivos

Alguns arquivos podem conter metadados, como:

- nome do arquivo;
- extensão;
- tipo de mídia;
- tamanho;
- duração;
- resolução;
- informações técnicas de codecs ou formatos;
- metadados incorporados ao próprio arquivo.

Essas informações podem ser lidas localmente quando forem necessárias para identificar o formato ou realizar corretamente a conversão.

O Pinho Konvertilo não utiliza esses metadados para criação de perfis pessoais, publicidade comportamental ou comercialização de dados.

## 4. Permissões e acesso ao armazenamento

Dependendo da versão do Android e da operação solicitada, o Pinho Konvertilo pode precisar utilizar mecanismos do sistema para que o usuário escolha arquivos ou locais de armazenamento.

O aplicativo procura utilizar os mecanismos de acesso fornecidos pelo próprio Android, concedendo acesso somente aos arquivos ou locais necessários para a operação solicitada.

O usuário mantém controle sobre os arquivos que escolhe abrir, converter e salvar.

Uma permissão concedida ao aplicativo não altera o compromisso descrito nesta Política: o acesso deve ser limitado às funcionalidades necessárias para conversão e gerenciamento dos arquivos escolhidos pelo próprio usuário.

## 5. Arquivos temporários

Algumas conversões podem exigir a criação temporária de arquivos intermediários, fragmentos ou dados de processamento dentro do armazenamento privado ou de áreas de trabalho utilizadas pelo aplicativo.

Esses dados são utilizados exclusivamente para concluir a operação solicitada.

Arquivos temporários podem permanecer durante uma conversão em andamento, em uma operação interrompida ou enquanto forem tecnicamente necessários para recuperação ou conclusão da tarefa.

Eles podem ser removidos pelo próprio aplicativo durante processos de limpeza, pela limpeza dos dados do aplicativo realizada pelo usuário ou pela desinstalação do aplicativo, conforme o comportamento do sistema Android.

Os arquivos finais salvos pelo usuário permanecem no dispositivo até que sejam excluídos pelo próprio usuário ou por outro aplicativo autorizado por ele.

## 6. Funcionamento offline

As funções de conversão foram projetadas para funcionar localmente e, sempre que possível, sem depender de conexão com a internet.

O processamento de documentos e mídias não exige que o conteúdo dos arquivos seja enviado a servidores do Pinho Konvertilo.

Algumas funções relacionadas à distribuição do aplicativo, compras, atualização, verificação de licença ou serviços fornecidos pela Google Play podem, entretanto, exigir uma conexão com a internet.

## 7. Conta de usuário

O Pinho Konvertilo não exige a criação de conta própria para realizar conversões.

O desenvolvedor não mantém um banco de contas pessoais do Pinho Konvertilo contendo nome, senha ou histórico de arquivos convertidos.

Por essa razão, não existe uma "conta Pinho Konvertilo" que precise ser excluída.

Contas utilizadas pela Google Play ou por outros serviços externos são administradas pelos respectivos fornecedores e estão sujeitas às políticas deles.

## 8. Pinho Konvertilo Free

A edição Free foi projetada para oferecer funcionalidades gratuitas de conversão.

A versão Free não exige pagamento para as funcionalidades disponibilizadas gratuitamente.

Enquanto não houver integração de publicidade ou serviços de análise de terceiros, a versão Free não utiliza anúncios ou ferramentas de rastreamento publicitário do desenvolvedor.

Caso isso seja alterado futuramente, esta Política será atualizada para refletir a nova forma de tratamento de dados.

## 9. Pinho Konvertilo Premium

O Pinho Konvertilo Premium é uma edição separada do aplicativo, destinada a oferecer ferramentas adicionais e recursos avançados de produtividade.

Quando a compra do aplicativo ou de produto digital relacionado ao Premium for realizada por meio da Google Play, o pagamento será processado pelo sistema de faturamento da Google Play conforme as regras aplicáveis à distribuição.

O desenvolvedor do Pinho Konvertilo não recebe diretamente informações completas do cartão bancário utilizado pelo usuário, como número integral do cartão, código de segurança ou credenciais bancárias.

A Google Play pode fornecer ao aplicativo ou ao desenvolvedor informações técnicas relacionadas à compra, como:

- confirmação de que uma compra foi realizada;
- identificador da transação ou compra;
- produto adquirido;
- situação da compra;
- informações necessárias para validar ou restaurar a aquisição.

Essas informações podem ser utilizadas somente para gerenciar o acesso à edição ou funcionalidade adquirida e para atividades administrativas legítimas relacionadas à transação.

As informações de pagamento processadas pela Google estão sujeitas às políticas e práticas de privacidade da própria Google.

## 10. Apoio voluntário ao projeto

O desenvolvedor disponibiliza uma forma opcional de apoio financeiro ao desenvolvimento do Pinho Konvertilo.

O apoio é uma contribuição voluntária e não concede conteúdo digital, funcionalidade Premium, vantagem exclusiva, prioridade, badge ou outro benefício dentro do aplicativo.

Ao escolher apoiar o projeto, o Pinho Konvertilo solicita ao Android que abra uma página externa de pagamento hospedada pela **Stripe** em `buy.stripe.com`.

O Pinho Konvertilo não coleta, processa nem armazena diretamente o número completo do cartão, código de segurança, credenciais bancárias ou outros dados de pagamento inseridos nessa página externa. Esses dados são tratados pela Stripe conforme suas próprias políticas e termos.

A página de apoio atualmente utiliza valor livre em BRL, com mínimo de R$ 1,50, valor recomendado de R$ 5,00 e sem máximo definido pelo aplicativo. O valor final é escolhido pelo próprio apoiador na página da Stripe.

O Pinho Konvertilo não utiliza uma contribuição voluntária para criar perfis publicitários do usuário.

## 11. Dados pessoais que o desenvolvedor não pretende coletar

O Pinho Konvertilo não foi projetado para coletar sistematicamente, para servidores próprios do desenvolvedor:

- conteúdo dos arquivos convertidos;
- fotografias ou vídeos do usuário fora daqueles que ele próprio selecionar para uma operação;
- lista de contatos;
- mensagens SMS;
- histórico de chamadas;
- localização precisa;
- dados biométricos;
- credenciais bancárias;
- senhas pessoais;
- histórico de navegação;
- conteúdo de outros aplicativos;
- lista de arquivos do dispositivo para fins de publicidade;
- informações destinadas à criação de perfil comercial do usuário.

Se uma futura funcionalidade passar a exigir tratamento diferente do descrito nesta Política, a documentação e, quando necessário, os mecanismos de consentimento serão atualizados.

## 12. Publicidade e rastreamento

No modelo atualmente previsto para o Pinho Konvertilo, o aplicativo não utiliza publicidade de terceiros.

Também não é objetivo do aplicativo utilizar os arquivos convertidos para rastreamento, publicidade direcionada ou criação de perfis de comportamento.

Caso anúncios ou ferramentas de análise sejam introduzidos futuramente, esta Política deverá ser atualizada para indicar de forma clara quais dados são coletados, por que são coletados, quais terceiros os recebem, durante quanto tempo são mantidos e quais controles estarão disponíveis ao usuário.

## 13. Compartilhamento de dados

O desenvolvedor do Pinho Konvertilo não vende nem comercializa os arquivos selecionados pelo usuário.

O conteúdo dos arquivos não é compartilhado com terceiros pelo desenvolvedor como parte normal do processo de conversão.

Dados relacionados a uma compra Premium poderão ser processados pela Google e por seus sistemas de pagamento conforme necessário para executar a transação, validar a compra ou cumprir obrigações legais e financeiras.

Informações também poderão ser tratadas quando isso for necessário para cumprimento de uma obrigação legal válida.

## 14. Venda de dados

O Pinho Konvertilo não vende arquivos pessoais, informações pessoais ou dados relacionados ao conteúdo convertido pelo usuário.

O modelo de monetização do aplicativo não depende da venda de dados pessoais.

## 15. Retenção de dados

Como os arquivos são processados localmente, o desenvolvedor normalmente não possui uma cópia deles para armazenar ou excluir remotamente.

Os arquivos de saída permanecem no armazenamento escolhido pelo usuário até que sejam excluídos pelo próprio usuário.

Preferências e configurações mantidas localmente pelo aplicativo podem permanecer no dispositivo até que:

- sejam removidas pelo aplicativo;
- os dados do aplicativo sejam apagados;
- o aplicativo seja desinstalado;
- o sistema operacional realize a limpeza correspondente.

Informações relacionadas a transações da Google Play podem permanecer nos sistemas da Google conforme as regras de retenção, contabilidade, segurança e legislação aplicáveis à própria Google.

## 16. Exclusão de dados

Como não existe uma conta própria obrigatória do Pinho Konvertilo, o usuário pode excluir os dados locais relacionados ao aplicativo utilizando os controles do Android.

Isso pode incluir:

- excluir manualmente arquivos convertidos;
- limpar arquivos temporários disponibilizados pelo aplicativo;
- limpar armazenamento ou dados do aplicativo nas configurações do Android;
- desinstalar o aplicativo.

A desinstalação do Pinho Konvertilo não necessariamente exclui arquivos finais que o próprio usuário tenha escolhido salvar em pastas públicas ou externas ao armazenamento privado do aplicativo.

Esses arquivos continuam sob controle do usuário.

Registros de compras mantidos pela Google Play são administrados pela Google e não podem ser removidos diretamente pelo Pinho Konvertilo.

## 17. Segurança

O Pinho Konvertilo adota como principal medida de privacidade a redução da quantidade de informações transmitidas para fora do dispositivo.

Sempre que possível, o processamento é realizado localmente.

O aplicativo procura utilizar os mecanismos de segurança e isolamento oferecidos pelo sistema Android.

Nenhum sistema eletrônico pode garantir segurança absoluta. O usuário também é responsável por manter seu dispositivo protegido, utilizar versões atualizadas do sistema quando disponíveis e controlar o acesso físico ao aparelho e aos arquivos produzidos.

## 18. Serviços de terceiros

Determinadas funcionalidades externas ao processamento de arquivos podem depender de serviços fornecidos por terceiros.

Isso inclui, principalmente, serviços da Google relacionados a:

- Google Play Store;
- distribuição e atualização do aplicativo;
- Google Play Billing;
- processamento e confirmação de compras;
- recursos técnicos da plataforma Android.

Esses serviços são operados pela Google e estão sujeitos às políticas próprias da empresa.

Quando o usuário escolhe realizar um apoio voluntário, o checkout externo é operado pela **Stripe**. O Pinho Konvertilo apenas solicita a abertura da página externa de pagamento; os dados financeiros fornecidos nessa página são tratados pela Stripe de acordo com suas próprias políticas e termos.

A utilização de um serviço externo não autoriza o Pinho Konvertilo a acessar livremente os dados mantidos por esse serviço.

### 18.1 Reconhecimento de texto (OCR)

Quando a funcionalidade de reconhecimento de texto (OCR) estiver disponível, o Pinho Konvertilo poderá utilizar o **Google ML Kit Text Recognition** com o modelo de escrita latina incorporado ao próprio aplicativo.

O conteúdo visual selecionado para OCR e o texto reconhecido são processados no dispositivo. De acordo com os termos do ML Kit, os dados de entrada e os resultados das APIs de ML Kit são processados no aparelho e não são enviados aos servidores da Google como conteúdo da operação de reconhecimento.

A documentação do ML Kit informa, porém, que seus SDKs podem tratar métricas técnicas de diagnóstico e uso, como informações do dispositivo e do aplicativo, identificadores por instalação, métricas de desempenho, configuração da API, tamanho de entrada e saída, versão da funcionalidade, tipos de evento e códigos de erro.

Na configuração atual do Pinho Konvertilo que inclui OCR:
- o modelo latino é empacotado com o aplicativo e não depende de download para reconhecer texto;
- o aplicativo não solicita a permissão Android `INTERNET`;
- o conteúdo dos arquivos selecionados para OCR não é usado para publicidade nem enviado a servidores do desenvolvedor;
- a integração e a declaração de Segurança dos dados da Google Play serão revisadas novamente antes de cada publicação relevante.

Referências do fornecedor:
- ML Kit — Terms & Privacy: https://developers.google.com/ml-kit/terms
- ML Kit — Google Play data disclosure: https://developers.google.com/ml-kit/android-data-disclosure

## 19. Direitos relacionados a dados pessoais

Quando houver tratamento de dados pessoais sujeito à Lei Geral de Proteção de Dados Pessoais — LGPD, Lei nº 13.709/2018 — o titular poderá exercer os direitos previstos na legislação aplicável.

Dependendo do caso, esses direitos podem incluir:

- confirmação da existência de tratamento;
- acesso aos dados;
- correção de dados incompletos, inexatos ou desatualizados;
- anonimização, bloqueio ou eliminação de dados tratados em desconformidade com a legislação;
- informações sobre eventual compartilhamento;
- revogação de consentimento quando o tratamento depender de consentimento;
- outros direitos previstos pela legislação aplicável.

Como o Pinho Konvertilo foi projetado para processar os arquivos localmente e não manter uma conta centralizada do usuário, em muitos casos o próprio usuário já possui controle direto sobre os dados existentes no dispositivo.

## 21. Alterações nesta Política

Esta Política poderá ser atualizada quando:

- novas funcionalidades forem adicionadas;
- o tratamento de dados mudar;
- novos serviços de terceiros forem integrados;
- houver alteração relevante nas regras da Google Play;
- houver mudança na legislação aplicável;
- forem necessárias melhorias de clareza ou segurança.

Quando ocorrer uma alteração relevante, a data indicada no início desta Política será atualizada.

Mudanças que impliquem nova coleta, novo compartilhamento ou nova finalidade de tratamento poderão exigir informações adicionais ou consentimento do usuário antes da utilização da funcionalidade correspondente.

## 22. Compromisso do Pinho Konvertilo

A proposta de privacidade do Pinho Konvertilo pode ser resumida da seguinte forma:

> **Se um arquivo pode ser convertido no próprio aparelho, ele não precisa sair do aparelho.**

O objetivo do projeto é oferecer ferramentas úteis de conversão sem transformar os arquivos pessoais do usuário em uma fonte de dados para publicidade ou comercialização.

Esta Política reflete esse compromisso.
